# LAD 2 - Персональная операционная система

Local Adaptive Dashboard 2 (LAD 2) — это персональная операционная система, которая работает локально в браузере с синхронизацией в облако.

## 🚀 Возможности

### 🔐 Авторизация
- Встроенная система аутентификации
- Защита маршрутов
- Локальное хранение данных

### 📊 Дашборд
- Переключение контекстов (Дом/Работа/Учеба)
- Кастомизация интерфейса
- Мгновенный доступ ко всем модулям

### ✅ Задачи (Tasks)
- Полноценный CRUD задач
- Статусы: К выполнению, В процессе, Выполнено
- Приоритеты: Низкий, Средний, Высокий
- Фильтрация и статистика
- Локальное хранение в IndexedDB

### 📅 Календарь
- Создание событий с датами начала и конца
- Выбор цвета события
- Просмотр событий на месяц
- Локальное хранение в IndexedDB

### 💰 Финансы
- Отслеживание доходов и расходов
- Категории (Зарплата, Еда, Транспорт и др.)
- Баланс и статистика
- Визуализация по категориям

### 📝 Заметки
- Создание и редактирование заметок
- Поддержка markdown
- Теги для организации
- Закрепление важных заметок
- Поиск по содержанию
- Локальное хранение в IndexedDB

### 👥 CRM
- Управление контактами
- Компания, должность, email, телефон
- Теги для классификации (Лид, Клиент, Партнёр)
- Заметки по контактам
- Отслеживание последних контактов
- Напоминания о follow-up
- Статистика по контактам

### 💪 Здоровье и Привычки
- Создание привычек с целями
- Категории: Здоровье, Фитнес, Обучение, Продуктивность, Благополучие
- Трекинг выполнения
- Стек (streak) дней
- Выбор цвета для привычки
- Ведение журнала выполнения

### 📧 Почта
- Входящие и отправленные
- Композитор писем
- Папки: Входящие, Отправленные, Черновики, Корзина
- Закладки (звёздочки)
- Маркировка прочитанных
- Интеграция с локальной БД

## 🛠️ Технологии

- **Next.js 14** - React фреймворк
- **TypeScript** - типизация
- **Dexie.js** - IndexedDB ORM
- **Zustand** - управление состоянием
- **Tailwind CSS** - стилизация
- **Lucide React** - иконки
- **UUID** - генерация уникальных ID

## 📦 Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Запуск продакшен-сервера
npm start
```

## 🔒 Безопасность

- Все данные хранятся локально в браузере
- Шифрование чувствительных данных
- Защита от XSS атак
- Валидация входных данных

## 🔄 Синхронизация

- Локально-первый подход (Local-First)
- CRDT для разрешения конфликтов
- Фоновая синхронизация
- Офлайн работа
