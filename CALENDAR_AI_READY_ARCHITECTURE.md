## 🧠 АРХИТЕКТУРНЫЙ ПАТТЕРН: Strategy + Dependency Injection

### 1. Единый интерфейс (абстракция)
Создай интерфейс `ISmartEngine`, который описывает все "умные" операции календаря:

```typescript
interface ISmartEngine {
  // Парсинг естественного языка в структуру события
  parseInput(text: string, context: 'home' | 'work'): Promise<ParsedEvent>;
  
  // Поиск лучших свободных слотов для задачи
  findBestSlots(
    durationMinutes: number, 
    options: SlotSearchOptions
  ): Promise<TimeSlot[]>;
  
  // Предложение категорий/тегов на основе названия
  suggestCategories(title: string): Promise<string[]>;
  
  // Проверка доступности (для будущих расширений)
  isAvailable(): Promise<boolean>;
}
```

### 2. Реализация №1: RuleEngine (работает сейчас, по умолчанию)
- **parseInput**: Использует Regex для поиска паттернов:
  - Даты: "завтра", "в пятницу", "15 мая", "через 2 дня"
  - Время: "в 15:00", "утром", "после обеда", "на 2 часа"
  - Пример: "Встреча с Олегом завтра в 15:00" → { title: "Встреча с Олегом", date: ..., time: ... }
  
- **findBestSlots**: Алгоритм на основе правил:
  - Фильтрует занятые слоты из локальной БД
  - Учитывает рабочие часы (настраивается: 9:00–18:00 для "work")
  - Учитывает буфер между событиями (настраивается: 15 мин)
  - Возвращает топ-3 слота, отсортированных по близости к "сейчас"
  
- **suggestCategories**: Простые правила:
  - Если в названии есть "клиент", "встреча", "звонок" → ["#работа", "#встреча"]
  - Если есть "дом", "семья", "отдых" → ["#личное"]
  - Если есть "спорт", "врач", "здоровье" → ["#здоровье"]

### 3. Реализация №2: AIEngine (заглушка на будущее)
- Создать класс `AIEngine`, который реализует `ISmartEngine`
- Методы пока возвращают `NotImplementedError` или делегируют на `RuleEngine` как fallback
- Подготовить структуру для:
  - Хранения API key (в настройках, не в коде)
  - Конфигурации провайдера (OpenAI/Anthropic/Local)
  - Обработки ошибок сети и таймаутов

### 4. Роутер (IntelligenceService)
Создать сервис, который выбирает реализацию динамически:

```typescript
class IntelligenceService implements ISmartEngine {
  constructor(private settings: AppSettings) {}
  
  async parseInput(text: string, context: Context) {
    if (this.settings.aiEnabled && this.settings.aiApiKey) {
      return new AIEngine(this.settings.aiApiKey).parseInput(text, context);
    }
    return new RuleEngine().parseInput(text, context);
  }
  // ... аналогично для других методов
}
```

### 5. Интеграция с настройками
Добавить в `UserSettings`:

interface UserSettings {

```

### 6. UI: Страница настроек интеграций
Создать компонент `SettingsIntegrations`:
- Переключатель "Включить AI-функции"
- Выпадающий список провайдеров
- Поле для API key (с кнопкой "показать/скрыть")
- Кнопка "Проверить соединение" (делает тестовый запрос)
- Текст-подсказка: "Без ключа календарь работает в режиме правил"

### 7. Тестирование
- Написать юнит-тесты для `RuleEngine.parseInput` с примерами:
  - "Завтра в 10 утра" → правильная дата и время
  - "Встреча в пятницу на 2 часа" → дата пятницы, длительность 120 мин
- Написать тесты для `findBestSlots` с моками занятого расписания
- Написать интеграционный тест для `IntelligenceService`: 
  - Без ключа → использует RuleEngine
  - С ключом → пытается использовать AIEngine
