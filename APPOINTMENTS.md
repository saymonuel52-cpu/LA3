# 📋 Модуль Записи Клиентов (Appointments)

## 🎯 Описание

Модуль для записи клиентов на процедуры. Идеально подходит для:
- Салонов красоты
- Массажных кабинетов
- Косметологических клиник
- Фитнес-тренеров
- Консультантов

## ✨ Возможности

### 1. Записи (Appointments)
- **Просмотр записей на день** с фильтрацией по статусу
- **Статусы записей**:
  - ⏳ Ожидает (pending)
  - ✅ Подтверждено (confirmed)
  - ✔️ Выполнено (completed)
  - ❌ Отменено (cancelled)
- **Быстрое подтверждение/завершение** записей
- **Статистика** на день:
  - Всего записей
  - Ожидают
  - Подтверждено
  - Выполнено

### 2. Клиенты (Clients)
- **База клиентов** с контактами
- **Статистика по клиенту**:
  - Общее количество визитов
  - Дата последнего визита
  - Дата следующей записи
- **Заметки** по каждому клиенту
- **Поиск и фильтрация**

### 3. Процедуры (Procedures)
- **Справочник процедур**
- **Настройки процедуры**:
  - Название
  - Описание
  - Длительность (минуты)
  - Цена (рублей)
  - Категория
  - Цвет для визуализации
- **Категории**:
  - Массаж
  - Косметология
  - Физиотерапия
  - Реабилитация
  - Другое

## 🚀 Использование

### Создание записи

1. Перейдите на вкладку **"Записи"**
2. Выберите дату
3. Нажмите **"+ Новая запись"**
4. Заполните форму:
   - Выберите клиента
   - Выберите процедуру
   - Укажите дату и время
   - Добавьте заметки (опционально)
5. Нажмите **"Создать запись"**

### Управление статусами

- **Ожидает** → **Подтверждено**: Клиент подтвердил визит
- **Подтверждено** → **Выполнено**: Процедура завершена
- **Удалить**: Отмена записи

### Добавление клиента

1. Перейдите на вкладку **"Клиенты"**
2. Нажмите **"+ Добавить клиента"**
3. Заполните форму:
   - Имя *
   - Телефон *
   - Email (опционально)
   - Заметки (опционально)
4. Нажмите **"Добавить"**

### Добавление процедуры

1. Перейдите на вкладку **"Процедуры"**
2. Нажмите **"+ Добавить процедуру"**
3. Заполните форму:
   - Название *
   - Описание (опционально)
   - Категория
   - Длительность (мин)
   - Цена (₽)
   - Выберите цвет
4. Нажмите **"Добавить"**

## 🎨 Дизайн

### Карточки записей
- Градиентный аватар клиента
- Информация о процедуре
- Время и длительность
- Статус с цветовой кодировкой
- Цена услуги

### Цвета статусов
- ⏳ Ожидает - Жёлтый
- ✅ Подтверждено - Синий
- ✔️ Выполнено - Зелёный
- ❌ Отменено - Красный

## 📊 База Данных

### Таблицы

#### Procedures (Процедуры)
```typescript
interface Procedure {
  id: string
  name: string
  description: string
  duration_minutes: number
  price: number
  category: string
  color: string
  created_at: string
  updated_at: string
  sync_version: number
}
```

#### Appointments (Записи)
```typescript
interface Appointment {
  id: string
  client_id: string
  procedure_id: string
  date: string
  time: string
  duration_minutes: number
  price: number
  status: 'pending' | 'confirmed' | 'completed' | 'cancelled'
  notes?: string
  reminder_sent: boolean
  created_at: string
  updated_at: string
  sync_version: number
}
```

#### Clients (Клиенты)
```typescript
interface Client {
  id: string
  name: string
  phone: string
  email?: string
  notes?: string
  total_visits: number
  total_spent: number
  last_visit?: string
  next_appointment?: string
  tags: string[]
  created_at: string
  updated_at: string
  sync_version: number
}
```

## 💡 Советы по использованию

### Для салонов красоты
- Создайте процедуры с разными длительностями
- Используйте цвета для категорий услуг
- Отмечайте постоянных клиентов в заметках

### Для массажных кабинетов
- Настройте типовые процедуры (массаж спины, всего тела и т.д.)
- Указывайте длительность с запасом на подготовку
- Записывайте особенности клиента в заметки

### Для консультантов
- Создавайте процедуры для разных типов консультаций
- Используйте теги для классификации клиентов
- Отмечайте повторные визиты

## 🔧 Технические детали

### Индексы БД
- `appointments`: date, time, status, client_id
- `clients`: name, phone
- `procedures`: category

### Автообновление статистики
При создании записи:
- У клиента увеличивается `total_visits`
- Обновляется `last_visit`
- Устанавливается `next_appointment`

### Local-First
Все данные хранятся локально в IndexedDB
Мгновенная работа без интернета
