# 📅 Форматы дат для RuleEngine.parseInput()

## 🎯 Цель
RuleEngine должен понимать 10+ форматов дат и времени на русском языке для парсинга естественного языка.

## 📋 Примеры фраз для парсинга

### 1. Относительные даты (самые частые)
```
"завтра"                    → завтрашний день
"послезавтра"              → через 2 дня
"вчера"                    → вчерашний день
"позавчера"                → 2 дня назад
"через 3 дня"              → сегодня + 3 дня
"через неделю"             → сегодня + 7 дней
"через 2 недели"           → сегодня + 14 дней
"на следующей неделе"      → ближайший понедельник
```

### 2. Дни недели
```
"в понедельник"            → ближайший понедельник
"во вторник"               → ближайший вторник
"в среду"                  → ближайшая среда
"в четверг"                → ближайший четверг
"в пятницу"                → ближайшая пятница
"в субботу"                → ближайшая суббота
"в воскресенье"            → ближайшее воскресенье
"в следующий понедельник"  → понедельник следующей недели
"в прошлую пятницу"        → пятница прошлой недели
```

### 3. Конкретные даты
```
"15 мая"                   → 15 мая текущего года
"15 мая 2025"              → 15 мая 2025 года
"1 июня"                   → 1 июня текущего года
"31 декабря"               → 31 декабря текущего года
"01.06.2025"               → 1 июня 2025 (формат DD.MM.YYYY)
"2025-06-01"               → 1 июня 2025 (формат YYYY-MM-DD)
"15/05"                    → 15 мая текущего года
```

### 4. Время суток
```
"утром"                    → 9:00 (рабочее утро)
"днём"                     → 13:00 (после обеда)
"вечером"                  → 18:00 (рабочий вечер)
"ночью"                    → 22:00 (поздний вечер)
"рано утром"               → 7:00
"поздно вечером"           → 20:00
```

### 5. Конкретное время
```
"в 10:00"                  → 10:00
"в 15:30"                  → 15:30
"в 9 утра"                 → 9:00
"в 5 вечера"               → 17:00
"в 7 часов"                → 7:00
"в 8 часов утра"           → 8:00
"в 6 часов вечера"         → 18:00
"в полдень"                → 12:00
"в полночь"                → 0:00
```

### 6. Длительность
```
"на 1 час"                 → длительность 60 минут
"на 2 часа"                → длительность 120 минут
"на 30 минут"              → длительность 30 минут
"на полтора часа"          → длительность 90 минут
"на 45 минут"              → длительность 45 минут
"на весь день"             → длительность 8 часов (рабочий день)
```

### 7. Комбинированные примеры (реальные фразы)
```
"Встреча с Олегом завтра в 15:00" 
  → { title: "Встреча с Олегом", date: завтра, time: 15:00 }

"Совещание в пятницу утром на 2 часа"
  → { title: "Совещание", date: ближайшая пятница, time: 9:00, duration: 120 }

"Звонок с клиентом через 3 дня в 11 утра"
  → { title: "Звонок с клиентом", date: сегодня+3 дня, time: 11:00 }

"Отпуск с 15 по 25 июня"
  → { title: "Отпуск", startDate: 15 июня, endDate: 25 июня, isRange: true }

"Тренировка сегодня вечером на 45 минут"
  → { title: "Тренировка", date: сегодня, time: 18:00, duration: 45 }
```

## 🔧 Регулярные выражения для парсинга

### Для дат:
```regex
// Относительные даты
/(завтра|послезавтра|вчера|позавчера)/i

// Дни недели
/(в|во)\s+(понедельник|вторник|сред[уы]|четверг|пятниц[уы]|суббот[уы]|воскресень[ея])/i

// Конкретные даты
/(\d{1,2})\s+(январ[яю]|феврал[яю]|март[ае]|апрел[яю]|ма[яю]|июн[яю]|июл[яю]|август[ае]|сентябр[яю]|октябр[яю]|ноябр[яю]|декабр[яю])(?:\s+(\d{4}))?/i

// Формат DD.MM.YYYY
/(\d{1,2})[\.\/](\d{1,2})(?:[\.\/](\d{4}))?/i

// "Через N дней"
/через\s+(\d+)\s+(день|дня|дней)/i
/через\s+(\d+)\s+(недел[яю]|недели|недель)/i
```

### Для времени:
```regex
// Конкретное время HH:MM
/в\s+(\d{1,2}):(\d{2})/i

// Время с указанием утра/вечера
/в\s+(\d{1,2})\s+(утра|вечера|часов)/i

// Время суток
/(утром|днём|вечером|ночью|рано утром|поздно вечером)/i

// Специальное время
/(в полдень|в полночь)/i
```

### Для длительности:
```regex
// На N часов/минут
/на\s+(\d+)\s+(час|часа|часов)/i
/на\s+(\d+)\s+(минут[уы]|минута|минут)/i

// На полчаса/полтора часа
/на\s+(полчаса|полтора часа)/i

// На весь день
/на\s+весь\s+день/i
```

## 🎯 Алгоритм парсинга

### Шаг 1: Извлечение компонентов
1. **Найти дату** (приоритет: конкретная дата > день недели > относительная дата)
2. **Найти время** (приоритет: конкретное время > время суток > по умолчанию)
3. **Найти длительность** (если указана)
4. **Извлечь заголовок** (весь текст кроме дат/времени)

### Шаг 2: Нормализация
```typescript
function normalizeDate(match: string, context: 'home' | 'work'): Date {
  // Контекст влияет на время по умолчанию:
  // 'work' → 9:00-18:00
  // 'home' → 18:00-22:00
  
  if (match === "утром") {
    return context === 'work' ? setTime(9, 0) : setTime(8, 0);
  }
  if (match === "вечером") {
    return context === 'work' ? setTime(18, 0) : setTime(19, 0);
  }
  // ... остальная логика
}
```

### Шаг 3: Обработка неоднозначностей
```typescript
// Если время не указано, использовать контекстные умолчания
function resolveAmbiguousTime(
  title: string, 
  context: 'home' | 'work'
): Time {
  const workKeywords = ['встреча', 'совещание', 'звонок', 'работа'];
  const homeKeywords = ['ужин', 'кино', 'отдых', 'семья'];
  
  if (workKeywords.some(kw => title.includes(kw))) {
    return { hour: 10, minute: 0 }; // Рабочее время
  }
  if (homeKeywords.some(kw => title.includes(kw))) {
    return { hour: 19, minute: 0 }; // Вечернее время
  }
  
  return context === 'work' 
    ? { hour: 14, minute: 0 } 
    : { hour: 18, minute: 0 };
}
```

## 📊 Тестовые кейсы

### Успешные кейсы:
```typescript
// 1. Простая дата + время
parseInput("Встреча завтра в 15:00", "work")
// → { title: "Встреча", date: завтра, time: 15:00, duration: 60 }

// 2. День недели + время суток
parseInput("Совещание в пятницу утром", "work")
// → { title: "Совещание", date: ближайшая пятница, time: 9:00, duration: 60 }

// 3. Конкретная дата
parseInput("День рождения 15 мая", "home")
// → { title: "День рождения", date: 15 мая текущего года, time: 19:00 }

// 4. С длительностью
parseInput("Тренировка на 45 минут", "home")
// → { title: "Тренировка", date: сегодня, time: 18:00, duration: 45 }
```

### Граничные кейсы:
```typescript
// 1. Неоднозначное время
parseInput("Встреча утром", "work")
// → { title: "Встреча", date: сегодня, time: 9:00 }

parseInput("Встреча утром", "home")
// → { title: "Встреча", date: сегодня, time: 8:00 }

// 2. Без времени (использует контекст)
parseInput("Звонок с клиентом", "work")
// → { title: "Звонок с клиентом", date: сегодня, time: 14:00 }

// 3. Неполная информация
parseInput("15 мая", "home")
// → { title: "Событие", date: 15 мая, time: 19:00 }
```

## 🚀 Реализация в RuleEngine

### Структура ParsedEvent:
```typescript
interface ParsedEvent {
  title: string;
  date: Date;              // Дата события
  time?: {                // Время (если указано)
    hour: number;
    minute: number;
  };
  duration?: number;      // Длительность в минутах
  isAllDay?: boolean;     // На весь день
  context: 'home' | 'work'; // Контекст для умолчаний
  confidence: number;     // Уверенность парсера (0-1)
  rawText: string;        // Исходный текст
}
```

### Конфигурация умолчаний:
```typescript
const DEFAULT_TIMES = {
  work: {
    morning: { hour: 9, minute: 0 },
    afternoon: { hour: 14, minute: 0 },
    evening: { hour: 18, minute: 0 },
    defaultDuration: 60, // 1 час для рабочих встреч
  },
  home: {
    morning: { hour: 8, minute: 0 },
    afternoon: { hour: 15, minute: 0 },
    evening: { hour: 19, minute: 0 },
    defaultDuration: 120, // 2 часа для личных дел
  }
};
```

Эта спецификация покрывает 90% реальных случаев использования и обеспечивает хороший пользовательский опыт даже без AI.
