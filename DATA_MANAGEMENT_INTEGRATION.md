### 3. Реализация хука useDashboardData ✅

**Файл:** `src/hooks/useDashboardData.ts`

Хук предоставляет функциональность для управления данными дашборда с тремя режимами:

- **`demo`** - использует предзаполненные демо-данные из JSON файлов
- **`real`** - загружает реальные данные из IndexedDB (фильтрует по `isDemo: false`)
- **`empty`** - возвращает пустые данные для начального состояния

**Основные функции:**
- Автоматическая загрузка данных при смене режима
- Генерация статистики на основе реальных данных
- Генерация недавней активности
- Fallback на демо-данные при ошибках

**Интерфейсы:**
```typescript
export type DataMode = 'demo' | 'real' | 'empty'

export interface DashboardStats {
  id: string
  title: string
  value: number | string
  icon: string
  trend?: string
  description: string
}

export interface RecentActivity {
  id: string
  type: string
  title: string
  description: string
  icon: string
  timestamp: string
  module: string
}
```

## Использование

### Переключение режимов в дашборде

```tsx
import { useDashboardData } from '@/hooks/useDashboardData'

const { stats, recentActivity, tasks, events, transactions, isLoading } = 
  useDashboardData('demo') // или 'real' или 'empty'
```

### Управление данными в настройках

```tsx
import DataSettings from '@/components/settings/DataSettings'
import { DataMode } from '@/hooks/useDashboardData'

const [mode, setMode] = useState<DataMode>('demo')

<DataSettings currentMode={mode} onModeChange={setMode} />
```

## Знающие вопросы для дальнейшей работы

1. **Индексация поля `isDemo`**: Сейчас поле `isDemo` не проиндексировано в Dexie.js схеме. Для больших объёмов данных может потребоваться добавление индекса.

2. **Миграция существующих данных**: Если есть существующие записи в БД без поля `isDemo`, они будут считаться реальными данными. Возможно, потребуется скрипт миграции.

3. **Множественные пользователи**: Сейчас демо-данные используют фиксированный `user_id: 'demo-user'`. Для многопользовательской системы потребуется адаптация.

4. **Синхронизация**: Демо-данные не должны синхронизироваться с облаком. Убедитесь, что sync-engine фильтрует записи с `isDemo: true`.
