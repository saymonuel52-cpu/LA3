## 🎯 Как Тестировать

### Онбординг
1. Удалите IndexedDB или очистите localStorage
2. Откройте приложение
3. Должен открыться онбординг
4. Выберите профиль → Завершите

### Тёмная Тема
1. Откройте Настройки (⚙️ → шестерёнка)
2. Нажмите на иконки ☀️ / 🌙 / 💻
3. Проверьте изменение цветов

### Резервное Копирование
1. Откройте Настройки → Резервное копирование
2. Нажмите "Скачать резервную копию"
3. Проверьте скачанный JSON файл

### Пустые Состояния
1. Откройте Tasks модуль
2. Если задач нет → увидите EmptyState
3. Создайте задачу → EmptyState исчезнет

### Error Boundary
1. Включите React DevTools
2. Создайте ошибку в компоненте
3. Должна появиться страница ошибки
