  - `demo` - демо-данные из JSON файлов

- Автоматическая загрузка данных
- Генерация статистики на основе реальных данных
- Генерация недавней активности
- Fallback на демо-данные при ошибках

**Экспортируемые типы:**

## 🚀 Использование

### Переключение режимов на дашборде

1. Откройте `/dashboard`
2. Используйте кнопки сверху для переключения:
   - **Демо-данные** - предзаполненные данные из JSON
   - **Реальные данные** - данные из вашей БД
   - **Пустой режим** - без данных

### Управление данными в настройках

1. Откройте `/settings`
2. В секции "Управление данными":
   - Выберите режим отображения
   - Нажмите "Загрузить демо-данные" для импорта
   - Нажмите "Удалить демо-данные" для очистки

## ⚠️ Известные ограничения

1. **Индексация**: Поле `isDemo` не проиндексировано в Dexie.js схеме. Для больших объёмов данных (>1000 записей) фильтрация может быть медленной.

2. **Миграция**: Существующие записи без поля `isDemo` будут считаться реальными данными (по умолчанию `undefined !== true`).

3. **Множественные пользователи**: Демо-данные используют фиксированный `user_id: 'demo-user'`. Для multi-user системы потребуется адаптация.
